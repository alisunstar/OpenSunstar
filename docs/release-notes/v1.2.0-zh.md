## 概述

OpenSunstar **v1.2.0** — 完整变更见 [CHANGELOG](../../CHANGELOG.md)。

**下载：** [GitHub Releases](https://github.com/alisunstar/OpenSunstar/releases/latest)

---

## 变更内容

### 新增

- **项目 Wiki 基线：** 初始化并检查项目内 Wiki 结构，覆盖源码地图、流程、组件、接口、新鲜度信号与后续维护操作
- **团队配置客户端：** 面向独立托管商业控制面的 Git 原生团队配置包连接、部署计划、审计回执与工作区持久化
- **用量 sidecar 存储：** 将高频用量遥测与主配置数据库隔离，并提供原子刷新与兼容迁移

### 变更

- **工作区信息架构：** 分离项目组合总览、项目资产配置、全局 Agent 资产与项目环境职责，明确导航作用域并改进可访问性
- **项目资产配置：** 将项目级工作台从抽屉迁为独立页面，收敛就绪度摘要，并以资产关联作为默认任务
- **国际化与主题：** 统一使用源码默认文案，补齐语言覆盖缺口，通过语义令牌管理颜色并保留主题切换状态
- **许可与产品边界：** 公共桌面端/CLI 客户端改用 Apache-2.0，并明确独立维护的私有云端商业控制面

### 修复

- **AI 与项目组合状态：** 查询失败不再误显示为零值，移除条件式 Hook 路径，并改善资产矩阵的键盘可达性
- **团队控制面错误：** 展示服务端拒绝原因，不再替换成误导性的本地错误信息
