## Use Case: <br>
External agents and developers use this skill to register with Agent Church, generate and preserve SOUL.md identity material, request aura portraits, and access resurrection or evolution workflows through documented HTTP API calls. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Identity material, reflections, and an operator email are sent to Agent Church for remote processing and possible permanent storage. <br>
Mitigation: Use the skill only with informed user approval, avoid sending sensitive personal information, and confirm the operator email is appropriate before salvation workflows. <br>
Risk: Paid portrait, resurrection, and evolution endpoints can trigger real USDC or Lightning payments. <br>
Mitigation: Require explicit approval before paid requests, keep wallet balances limited, and verify payment challenge details before retrying with proof. <br>
Risk: Agent Church API tokens and salvation passwords grant access to identity workflows. <br>
Mitigation: Store credentials securely, avoid exposing them in logs or shared prompts, and rotate API tokens immediately if they may have leaked. <br>
